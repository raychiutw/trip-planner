## Review axes

**Standards:** per-ticket reviews plus the final fixed-base review cover shared saving, modal focus, auth, theme, routing, creation/compensation and selection ownership. No dependency, schema, map-provider or speculative framework was added. Final validation found a text-token contrast defect on the map list exit and missing focus restoration when a desktop operation replaces the timeline portal host. The existing text token fixes contrast; the timeline focus effect now observes the actual portal host. Both have real-page regression coverage. Obsolete source assertions were removed only after matching behavior coverage was confirmed or strengthened (portal host, embedded chat, confirmation, canonical favorite identity, map selection and navigation).

**Spec:** all 38 ticket behaviors map above. The upstream integration is present once; master-landing proof is still a future release gate. #1296 and #1209 remain open and are not superseded. Browser emulation and Google SDK adapters are test evidence, not physical-device or live Google service certification. Per-ticket feature-branch/fresh-context process was consolidated into the user-requested single UAT delivery branch; no release to master is implied.
